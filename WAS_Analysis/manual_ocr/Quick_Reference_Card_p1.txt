You can quickly get started playing The Ancient Art of War at Sea by learning the simple basics outlined
on this card.

IMPORTANT NOTE FOR TANDY 1000 USERS

In addition to the 4-color CGA version of The Ancient Art of War at Sea, a special 16-color version for
Tandy 1000 computers is included in this package.

If you have a Tandy 1000 use the disk marked VERSION FOR TANDY 1000 SERIES and type WAST to

start the game, after following the start up instructions in the manual.

The 3.5” disk in this package contains both the 4-color CGA version and the 16-color Tandy version of
the game.

QUICK START

The first time you play, read “Getting Started” at the beginning of Book | in the manual, then refer back
to this card.

When “GO TO WAR’ is displayed the sail press Enter to begin. Until the campaign actually begins, you
can back up to a previous screen by pressing Esc.

GAME COMMANDS

To use a command that is shown on the screen, press the indicated key, or if there is none, type the first
letter of the command. When a command is discussed in the manual the key to press will be in boldface:
Zoom (press Z to Zoom). .

Pause can be used to freeze the game, sometimes even when it is not displayed on the command line.

The white cross-shaped pointer that appears on the screen during a campaign is called the marker, and
can be moved with the arrow keys on the keypad or by using a joystick.

Keyboard Control: Use the arrow keys to move the marker up, down, left and right. The 1, 3, 7, and 9
keys will move the marker diagonally. Use — (minus) or the Tab key to scroll the map up; + (plus) or
Ctrl to scroll the map down.

Joystick Control: Activate the joystick at Ye Olde Options Shoppe if you haven’t done so already (see
“Getting Started” in the manual). When using the joystick:

Button 1 same as the Enter key

Up and Down with button 1 pressed scrolls the map

Button 2 moves between Screen and Command Line
Button 1 selects a command

Button 2 same as the Space bar

The keyboard can still be used when the joystick is activated.
